# v8 playback and listening design

Only the first queue track gates startup. Remaining tracks download through the existing bounded pool. A shared client startup promise prevents duplicate starts. Browser audio permissions remain visible through the Play action.

For You ranks artists from persistent completed-play ratios, skip penalties and 30-day recency decay. Similar-track discovery falls back to source search. Queue tracks and recent listening events are excluded. Events have per-play IDs to deduplicate replayed reports; history is bounded to 1,000 records. Crossfade completion records the outgoing track.
